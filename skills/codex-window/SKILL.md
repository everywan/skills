---
name: codex-window
description: 创建或联动修改三个 Codex 内置每日定时任务，以极短请求尝试启动五小时额度窗口。
---

使用 Codex 内置 automation_update 管理任务，不使用 cron、脚本或常驻进程。

- 开始时间默认 09:00，时区默认 Asia/Shanghai；用户指定时采用其设置。
- 三个每日时间为开始时间、+305 分钟、+610 分钟，跨午夜按 24 小时取模。
- 固定名称：Codex Window 1、Codex Window 2、Codex Window 3。
- 先查找同名已有自动化，再创建缺失任务或更新现有任务，避免重复。修改开始时间时同步更新全部三个。
- 每个任务使用独立新会话的 cron 自动化，不使用携带本聊天历史的 heartbeat。按工具实际支持的字段配置每日准确时间，不把小时和分钟分别列举而产生组合时间。
- 提示词统一为：`只回复 OK，不读取文件，不调用工具。`
- 使用可用的最低成本模型和最低支持的推理档位。优先无项目；若工具要求项目，先 list_projects 并沿用用户选定或当前项目。不要调用管理 Skill 作为任务提示词。
- 保持任务 ACTIVE；可用时设 notificationPolicy=failed_runs_only。更新保留其他已有配置。
- 完成后只报告三个时间和时区。不要声称任务能重置额度；是否启动目标窗口需实际验证。

例：开始 08:30 → 每天 08:30、13:35、18:40。
